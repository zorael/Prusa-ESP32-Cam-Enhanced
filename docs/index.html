Prusa ESP32-Cam Enhanced

Flash your ESP32-CAM directly from this page — version __VERSION__

This browser can't talk to serial devices. Use Chrome or Edge on desktop, or flash from the command line below. Serial access was blocked. This page must be served over HTTPS.

Before you start

  • Board: AI Thinker ESP32-CAM. Other boards aren't verified against this build yet.
  • You need a USB–serial adapter. The ESP32-CAM has no USB port of its own.
  • To enter flash mode: connect GPIO0 to GND, then power on or press reset. Remove the jumper afterwards, or it will boot back into the bootloader.
  • Chrome or Edge on desktop. Firefox and Safari don't implement WebSerial.

This will clear your settings

Yes, even without choosing “erase”. The factory image is a single continuous block starting at address 0, so the padding between partitions gets written too — including the area holding your WiFi credentials and Prusa Connect token. Expect to run through setup again after flashing from this page. That's correct for a new device.

Already running this firmware and just want the new version? Flash the application on its own, which leaves everything else alone: 

esptool.py --chip esp32 write_flash 0x10000 firmware-ai_thinker.app.bin

Only use that on a device already running this firmware. It doesn't write the partition table, so it can't set up a blank board.

Command line instead

Download firmware-ai_thinker.factory.bin from the latest release, then:

esptool.py --chip esp32 write_flash 0x0 firmware-ai_thinker.factory.bin

Flash the .factory.bin, not the .app.bin. The factory image includes the partition table; this firmware does not use the ESP32 default one, so flashing the app alone onto a mismatched table produces a device that won't boot.

After flashing

  • The camera starts a setup access point named ESP32_camera_*.
  • Connect to it and open 192.168.0.1 to enter your WiFi details.
  • Once on your network it's reachable at prusa-esp32cam.local.
  • Add the token and fingerprint from Prusa Connect to start uploading.
